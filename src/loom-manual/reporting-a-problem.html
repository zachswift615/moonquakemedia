If LOOM does something you did not expect, you can send a report to the person who makes it. LOOM writes the report to a file, and you send the file.

Writing a report

Choose File ▸ Report a Problem, or press ⇧⌘R.

LOOM writes a text file to your LOOM folder and opens it. The notice line at the bottom of the window shows the file's full path. The file is named loom-report- followed by the date and time, so two reports never overwrite each other.

Read the file before you send it. What you see in it is the whole report. When you are ready, attach it to an email to support@moonquakemedia.com and describe what you were doing.

What is in the report

The report has three parts.

What LOOM told you this session. Every message LOOM put on the notice line, newest first, with the time it appeared. This is the same text you saw at the bottom of the window.

The session before this one, if there was one. LOOM keeps the previous session's messages as well as the current one. If LOOM stopped unexpectedly, the report says so and includes the session that stopped, because by the time you write the report you have already restarted LOOM.

The loop geometry. For each track: where its loop starts, how long it is, where its read and write cursors are, how many times it has turned, and how far each pair of tracks has drifted apart. For each instrument track: how long its loop is, where its first pass began, and where the loop is now. This records what the audio engine did rather than what LOOM said about it, and it often answers a timing question on its own. It covers the current session only. To write it on its own at any time, press ⇧⌘G.

What is not in the report

The report does not contain audio, recordings or any part of your songs. It does not contain your licence, your email address, or anything about your computer beyond LOOM's own version number.

LOOM does not send it

LOOM makes no network connection. It writes the file and opens it, and nothing else happens until you attach the file to a message yourself. See Privacy.

The session log

The report reads from a record LOOM keeps while it runs.

To read this session's record in LOOM, choose View ▸ Show Logs, press ⇧⌘L, or press LOG at the right-hand end of the notice line. It shows the same messages as the report, newest first, without your having to write a report. You can select and copy any of it. See Session log.

The record is also kept as two files on disk. The report reads these files, and they hold the session before this one:

  • session-log.txt — this session
  • session-log-previous.txt — the session before it

Both are in your LOOM folder, at ~/Library/Application Support/LOOM/. LOOM keeps only these two files. When you start LOOM, the current log becomes the previous one and replaces the older file.

The log records what LOOM displayed on the notice line, in the same order. It adds a line only when the notice line changes, so a message that repeats appears once, as you saw it. The log also begins with a line of its own, naming the version of LOOM you are running and the time the session started.
